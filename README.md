# PyQt5-Weather-App
A simple desktop weather app built with Python and PyQt5
## ✨ Features
- **Real-Time Data:** Fetches live temperature, weather descriptions, and conditions via OpenWeatherMap API.
- **Dynamic UI:** Built with PyQt5, featuring responsive layouts and custom styling via QSS.
- **Robust Error Handling:** Catches invalid city inputs or connection failures gracefully, displaying friendly warning alerts instead of crashing.

## 🛠️ Tech Stack
- **Language:** Python 3.x
- **GUI Framework:** PyQt5
- **API Integration:** `requests` library
